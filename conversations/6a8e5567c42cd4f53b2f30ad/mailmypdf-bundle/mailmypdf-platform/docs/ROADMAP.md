# Platform Roadmap

## v0.1 Foundation

- Core contracts
- Document abstraction
- Provenance
- Facts
- Evidence
- Timeline primitives
- Deadline primitives
- Structured AI contract
- Evaluation fixtures and harness
- Proof/audit contracts
- MailMyPDF fulfillment adapter boundary
- Initial design tokens

## v0.2 Workflow

- Event-driven workflow model
- Conditions and branching
- Scheduled actions
- Approvals
- Retry/idempotency primitives
- Notification contracts

## v0.3 Intelligence

- Production extraction adapters
- Contradiction engine
- Evidence graph
- Deadline rule packs
- Evaluation dashboards
- Regression suite across verticals

## v0.4 Agent Infrastructure

Only after deterministic services are mature:

- Capability registry
- Tool registry
- Policy engine
- Approval engine
- Agent runtime
- Agent audit trail

## v1.0 Platform

A versioned, documented set of packages that can be consumed safely by multiple production verticals with compatibility guarantees and migration tooling.
