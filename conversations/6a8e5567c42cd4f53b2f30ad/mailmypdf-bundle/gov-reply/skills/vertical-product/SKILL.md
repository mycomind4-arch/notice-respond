# Vertical Product Skill

Build the smallest complete workflow that feels like a real product.

Required initial path:
RECEIVE → UNDERSTAND → DEADLINE → EVIDENCE → STRATEGY → RESPONSE → REVIEW → PROOF → SUBMIT.

Prioritize:
- exceptional document analysis
- clear next actions
- source-backed facts
- deadline visibility
- professional response quality
- explicit review before consequential actions
- polished case workspace UX

Avoid premature platform duplication, broad analytics, complex organizations, autonomous agents, and large taxonomy projects unless the MVP proves they are necessary.

The UI should communicate confidence without pretending certainty. Empty states, warnings, loading states, error states and mobile behavior are part of the product, not afterthoughts.
