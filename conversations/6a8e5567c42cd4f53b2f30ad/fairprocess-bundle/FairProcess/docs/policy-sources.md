# Policy sources

Policy data is a software representation of a procedural checkpoint, not legal
advice. It must be reviewed before production activation and rechecked whenever
the underlying law changes.

## Humboldt County recordation pilot

- Humboldt County Code § 352-4, Method of Giving Notice:
  https://humboldt.county.codes/Code/352-4
- Humboldt County Code § 352-23, Imposition of Administrative Civil Penalty
  Lien: https://humboldt.county.codes/Code/352-23
- Humboldt County Code table of contents:
  https://humboldt.county.codes/Code/contents
- Humboldt County official Code Enforcement page:
  https://humboldtgov.org/2447/Code-Enforcement

The initial rules deliberately report `not_located`, not `missing` or
`unlawful`. Sections 352-4(c) and 352-4(d) specify that certain documents must
be recorded and specify an earliest recording date, but do not state a maximum
number of days after that date in the text reviewed for this foundation.

Policy review status: **engineering draft; legal review required before use in
a customer-facing conclusion.**
