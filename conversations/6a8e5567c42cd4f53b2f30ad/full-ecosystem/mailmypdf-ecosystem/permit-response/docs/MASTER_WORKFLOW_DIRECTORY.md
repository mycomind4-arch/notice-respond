# Permit Response — Master Workflow Directory

This repository is the master product for permit, planning, inspection, and correction-response workflows.

Initial workflow families:
- permit correction response
- permit denial response
- building inspection response
- planning department comments
- zoning/application response
- resubmission cover response

Before creating additional permit-related products, first check whether the workflow belongs here. Shared identity, documents, property data where applicable, mailing, proof, billing, and UI belong to the platform or the relevant shared vertical foundation.
