# Debt Defense — Master Workflow Directory

This repository is the master product for debt-collection correspondence, validation, and dispute workflows.

Initial workflow families:
- debt validation request
- respond to debt collector
- collection account dispute
- request for account documentation
- dispute incorrect balance
- collection correspondence record

Each workflow should have distinct search intent, source documents, evidence needs, and response structure. Shared identity, documents, mailing, proof, billing, and UI belong to the platform layer. Legal conclusions and jurisdiction-specific rights require authoritative sources.
