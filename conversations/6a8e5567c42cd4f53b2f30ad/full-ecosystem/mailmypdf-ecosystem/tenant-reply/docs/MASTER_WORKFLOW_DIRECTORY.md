# Tenant Reply — Master Workflow Directory

This repository is the master product for tenant/landlord correspondence workflows.

Initial workflow families:
- landlord notice response
- repair/maintenance response
- lease correspondence
- security deposit dispute
- rent dispute response
- move-out/documented condition response

Each workflow should have a distinct search intent, inputs, evidence model, response structure, and canonical page when warranted. Shared identity, documents, mailing, proof, billing, and UI belong to the platform layer.
